# 📦 ระบบคลังอุปกรณ์และยืม-คืนพัสดุ (Web-Based Asset & Stock Management)

ระบบติดตามอุปกรณ์ (Asset Tracker) ที่ออกแบบมาเพื่อแก้ปัญหาอุปกรณ์หาย ไม่รู้ว่าใครยืมไป หรือลืมส่งคืน เหมาะสำหรับ **ห้องปฏิบัติการ/ห้องแล็บโรงเรียน, ชมรมกิจกรรม, ฝ่ายโสตทัศนูปกรณ์, ช่างอาคาร, และร้านเช่าชุด/อุปกรณ์**

---

## ✨ ความสามารถหลักของระบบ (Features)

1. **สแกน Barcode / QR Code ผ่านกล้องเว็บแคม หรือกล้องมือถือ/แท็บเล็ต**:
   - ใช้ไลบรารี `html5-qrcode` สแกนรหัสอุปกรณ์ได้ทันที หรือใช้เครื่องสแกนบาร์โค้ด USB ได้โดยตรง
   - ดึงข้อมูลอุปกรณ์ สต็อกคงเหลือ และประวัติผู้ยืมค้างอยู่แบบ Real-time
2. **ระบบพิมพ์สติกเกอร์ QR Code Label**:
   - สร้าง QR Code ประจำอุปกรณ์แต่ละชิ้น เพื่อพิมพ์ติดบนตัวเครื่องได้ทันที
3. **ระบบบันทึกการยืม (Borrowing)**:
   - บันทึกชื่อ-นามสกุล, เบอร์โทรศัพท์, สังกัด/แผนก/ชั้นเรียน, วัตถุประสงค์ และกำหนดส่งคืน
   - คำนวณตัดสต็อกคงเหลืออัตโนมัติแบบ Atomic Transaction
4. **ระบบรับคืนอุปกรณ์ (Returning)**:
   - ตรวจสอบรายการค้างคืน กดรับของคืนพร้อมบันทึกสภาพอุปกรณ์
   - คืนจำนวนกลับเข้าคลังสต็อกทันที
5. **ระบบแจ้งเตือนผ่าน LINE Notify / Webhook**:
   - แจ้งเตือนเมื่อมีรายการยืมใหม่
   - แจ้งเตือนเมื่อรับคืนของ
   - **ระบบ Auto-Cron Alert**: ตรวจสอบรายการที่ใกล้ถึงกำหนดคืนหรือค้างส่ง ทุกวันเวลา 08:30 น.
   - มีปุ่มกดทดสอบและกดแจ้งเตือนรายการค้างส่งแบบ Manual ได้ทันที
6. **Dashboard สรุปสถิติ & ประวัติย้อนหลัง**:
   - สรุปจำนวนอุปกรณ์ทั้งหมด, พร้อมใช้งาน, กำลังถูกยืม, และเกินกำหนดส่งคืน (Overdue)
   - ฟิลเตอร์ค้นหาและดูสถานะย้อนหลังได้ตลอดเวลา
