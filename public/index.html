# อุปกรณ์ ผู้ยืม / สังกัด / ติดต่อ วัตถุประสงค์ วันที่ยืม กำหนดคืน สถานะ ดำเนินการ

ตั้งค่าการแจ้งเตือน LINE Notify / Webhook

ระบบจะส่งแจ้งเตือนอัตโนมัติเมื่อ: มีการยืมอุปกรณ์ใหม่, มีการคืนอุปกรณ์, และสรุปแจ้งเตือนอุปกรณ์ที่ครบกำหนดส่งหรือค้างคืนทุกวัน

(ขอรับ Token ได้ฟรีที่ notify-bot.line.me แล้วเชิญ LINE Notify เข้ากลุ่มห้องเครื่องมือ)

หากไม่ใช้ LINE Notify สามารถนำ Webhook URL ของ Discord/Slack มาใส่เพื่อรับแจ้งเตือนได้เช่นกัน

💡 กำหนดการทำงานของระบบแจ้งเตือนอัตโนมัติ:

• ระบบตั้งเวลาตรวจสอบรายการค้างส่งอัตโนมัติทุกวันเวลา 08:30 น. (node-cron)

• หากยังไม่ได้ตั้งค่า Token ข้อความแจ้งเตือนจะถูกบันทึกและแสดงที่หน้า Console Server เพื่อความปลอดภัย
